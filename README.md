# Minkyung Research Notes

GitHub Pages용 Jekyll 연구노트입니다.

## 새 논문 리뷰 추가

1. `_posts` 폴더에 `YYYY-MM-DD-short-title.md` 파일을 만듭니다.
2. 기존 예시 글의 맨 위 `---` 사이 정보를 복사해 제목·설명·태그만 바꿉니다.
3. 그 아래부터 평소처럼 Markdown으로 리뷰를 작성합니다.
4. GitHub에 올리면 홈 목록, 주제 필터, 검색, 글 목차가 자동 생성됩니다.

## 적용

이 폴더 안의 파일을 `leesanghu.github.io` 저장소 최상단에 그대로 업로드하세요. 기존 `index.md`와 `README.md`는 새 파일로 교체합니다.
