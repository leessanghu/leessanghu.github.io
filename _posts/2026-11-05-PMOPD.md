## 0. Abstract

MOPD(Multi-teacher on-policy distillation) 가 언어모델에 특화된 능력을 통합 하는 방법으로 떠오르고 있음.

MOPD는 공유 파라미터 내에서 여러 능력 통합해야하고 하나의 도메인 개선이 다른 도메인에서 얻은 능력 억제하는 **capability seesaw** 현상을 해결해야됨.

MOPD 과정 중 서로 다른 작업의 파라미터 업데이트가 각자의 **low-dimensional subspace** 빠르게 집중된다는 점 발견

Gradient와 Optimizer 업데이트 모두 투영해 task 방향 방해하는 구성요소 제거하는 **PMOPD(Projection-based Multi-Teacher On-Policy Distillation)** 제안


## 1. Introduction

Base Model에서 수학, 추론, 코드와 같은 도메인별로 별도의 Teacher 모델 학습하고 이를 Student Model에 증류 하는것이 MOPD

MOPD는 여러 teacher모델이 동일한 student 파라미터에 작용하게 되며, 이는 한가지 능력을 향상시키면 다른 능력이 억제되는 **capability seesaw** 현상 생길 수도 있음

본 논문은 OPD의 업데이트 기하학적인 부분에 접근

Task 별 누적 update가 안정적인 저차원 subspace를 형성함을 확인

Gradient와 Optimizer update에 double projection을 적용해 간섭을 완화함

Qwen, Llama에서 기존 벤치마크보다 모든 테스크에서 성능 향상했음



## 2. Related Work

기존 OPD 방법은 여러 task-specialized 모델을 단일 student로 통합하는 데 효과적이지만, teacher의 **output velocity만 매칭**하는 endpoint signal만 존재. Student 내부의 representation이 어떻게 변화해야 하는지에 대한 직접 감독이 없어 학습이 불안정.

## 3. Method

- **Output velocity matching 확장**: teacher를 넘어서는 학습 목표 설정
- **Representation change alignment**: student 내부 feature의 변화 방향에 명시적 제약 추가
- Student가 자신의 denoising trajectory로 teacher를 쿼리하는 on-policy 방식 유지

## 4. Takeaways

- OPD의 내부 dynamics를 처음으로 명시적으로 제어한 프레임워크
- Output-level 감독 + Internal-level 감독의 결합이 핵심
- Distillation을 통한 경량화와 multi-task 통합 연구의 최신 흐름
